# Blackbody Radiation in Spherical Cavities: A Theoretical Study of the Discrete Spectrum

This repository contains the Python code used to generate the figures for the article:
**"Blackbody Radiation in Spherical Cavities: A Theoretical Study of the Discrete Spectrum"** by W. S. Elias and C. Molina.

## Prerequisites

The code requires Python 3 and the following libraries:
- `numpy`
- `scipy`
- `matplotlib`
- `pandas`

You can install the dependencies using `pip`:
```bash
pip install -r requirements.txt
